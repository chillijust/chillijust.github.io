# Archiv

**Hier steht nichts, was noch zu tun wäre.** Diese Dateien sind Pläne und Befunde, die
abgearbeitet sind; sie liegen hier, weil sie erklären, *warum* etwas so gebaut wurde —
nicht, weil daraus noch Arbeit folgt.

Wer wissen will, was gilt, liest `CLAUDE.md`, `docs/architektur.md` und die ADRs unter
`docs/decisions/`. Was in diesen Dateien einer heutigen Regel widerspricht, ist überholt:
Sie werden **nicht** nachgeführt.
